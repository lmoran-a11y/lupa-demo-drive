#🚗 Proyecto Lupauto

##🛠️ Stack Tecnológico

#Este sistema fue construido con herramientas de alto rendimiento para asegurar escalabilidad y rapidez:

    Frontend: React (Interfaz dinámica y amigable).

    Backend: Node.js con TypeScript (Lógica robusta y tipado seguro).

    Base de Datos: MongoDB (Flexibilidad para gestionar historiales y publicaciones).

#Para ejecutar el backend, sigue los siguientes pasos:
    
    1. cd LUPA-DEMO-DRIVE/backend

    2. Instala las dependencias de tu proyecto:

        npm install cors dotenv express mongoose nodemon ts-node @types/cors @types/express @types/node typescript
    
    3. Ejecuta el servidor de Node.js:

        npm run dev

#Para ejecutar el frontend, sigue los siguientes pasos:
    
    1. cd LUPA-DEMO-DRIVE/frontend

    2. Instala las dependencias de tu proyecto:

        npm install react react-dom react-router-dom @types/react @types/react-dom @vitejs/plugin-react vite @vitejs/plugin-react-refresh @types/react-router-dom typescript vite-plugin-svgr vite-plugin-windicss windicss @windicss/plugin-typography @types/node node @types/node @types/react-router-dom @types/react-router-dom vite-plugin-windicss vite-plugin-svgr @vitejs/plugin-react-refresh @vitejs/plugin-react @types/react @types/react-dom react-router-dom react-dom typescript

    3. Ejecuta el servidor de Vite:

        npm run dev
